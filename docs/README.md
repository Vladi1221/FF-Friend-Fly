# Documentación — Splitwaisito

Todo lo que armamos antes de escribir código: la idea, el diseño y cómo laburamos en equipo. Si tenés una duda de "para qué es esto" o "cómo se hace tal cosa", está acá antes de preguntar en el grupo.

- **wireframes-mvp.pdf** — las 6 pantallas núcleo del MVP (login, grupos, detalle de grupo, cargar gasto, saldar deuda, perfil), con la paleta y el diseño final.
- **backlog-mvp.pdf** — las 25 tareas del MVP con su historia/instrucción técnica, tamaño y dependencias. La versión editable y con estado en vivo está en el [tablero de Trello](https://trello.com/b/KnB9B2kP/splitwaisito).
- **guia-flujo-trabajo.pdf** — cómo es el flujo de trabajo con Git/GitHub paso a paso (rama, commits, PR, review, merge), pensada para quien nunca usó ramas ni Pull Requests.
- **ficha-tecnica-splitwaisito.pdf** — el documento formal del proyecto: concepto, alcance del MVP, justificación de las categorías de gasto, stack técnico, arquitectura, mecanismo de pago y proceso de creación con IA. Es lo que se muestra si el docente pide el detalle completo.
- **planilla-uso-ia.xlsx** — registro de uso de IA que pide la consigna. **Cada uno suma sus propias filas** a medida que usa IA para algo del proyecto (tiene una hoja "Cómo completar" con el detalle).

## Algo cambió desde acá

Estos PDFs son una foto de un momento (01/09). Las decisiones técnicas siguen vivas en `CLAUDE.md` (raíz del repo) y en el tablero de Trello — si hay una diferencia entre lo que dice un PDF y lo que dice `CLAUDE.md` o Trello, gana lo más nuevo.
